# Mac Settings and the Windows/Linux settings page

Every control of the Mac app's Settings window (Sources/MiniGateway/Settings.swift) and its counterpart in
`minigw serve` (the settings page `/minigw/settings`, the admin API in [admin-api.md](admin-api.md) and
`serve.json`). Mac only: Siri AI, Apple Foundation Models, the WebDAV folder mount (direct mode), native mode,
`minigw run`, and the build network switches of worktree mode.

A row that states a difference ends with **Test:**, the acceptance tests that pin it: Go tests (`client/`, `go test`)
for `minigw serve`, run on Windows, Linux and macOS (a name ending in `Windows` runs on Windows only; some skip a
platform, as noted), and Swift tests (`swift test`) for the Mac app. "Manual (tester step)" is checked in the test
round, "no test" is not pinned.
